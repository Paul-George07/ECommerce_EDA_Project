# ECommerce_EDA_Project

This project provided valuable insights into the dataset through effective Exploratory Data Analysis (EDA). By analyzing customer behavior, sales patterns, and key business metrics, we identified important trends such as top-performing cities, high-revenue product categories, and customer spending habits.

Data cleaning and visualization helped in understanding the structure and quality of the data, making it easier to draw meaningful conclusions. The use of charts and statistical methods made complex data more understandable and supported better decision-making.

Overall, this project demonstrates how raw data can be transformed into valuable insights through systematic exploration and visualization.
